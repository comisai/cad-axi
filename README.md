# cad-axi

A command-line tool that lets AI agents read, create and edit CAD drawings. It works with DWG and DXF files. It is an AXI, an [agent experience interface](https://axi.md), built to run inside Comis.

> **Status:** design. There is no code yet. The plans are in `docs/`.
